# Cat Loader 0.4.6

로컬 모델 화면 하단의 실행 버튼 왼쪽에 대상 모델명을 굵게 표시합니다. 모델을 고르면 이름도 함께 바뀌며, 다운로드나 서버 실행 중 다른 작업 화면으로 이동해도 대상 모델을 확인할 수 있습니다. ANIS 모델명도 선택한 표시 언어에 맞게 나옵니다.

Release 빌드와 기존 네이티브 UI 전체 회귀검사를 수행했습니다. 6개 모델 선택 화면과 최소 크기에서 모델명·실행 버튼 배치를 확인했습니다. 기존 0.4.5의 기능과 데이터 저장 위치는 유지합니다.

Windows x64 단일 EXE이며 .NET 10 Desktop Runtime과 ASP.NET Core Runtime 10(x64)이 필요합니다. 기존 Cat Loader를 완전 종료한 뒤 새 EXE를 실행하세요.
