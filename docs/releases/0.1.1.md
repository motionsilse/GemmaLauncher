# Cat Loader 0.1.1

PLaMo 3 Translate **0.8B**와 **2B**를 로컬 모델 목록에서 ANIS Trans 바로 위에 추가했습니다. 앱에서 모델을 선택하고 **다운로드하고 시작**을 누르면 Preferred Networks의 공식 GGUF를 받아 실행합니다. 기본 모델은 총 8개입니다.

| 모델 | 양자화 | 모델 파일 |
|---|---|---:|
| PLaMo 3 Translate 0.8B | Q4_K_M | 0.57 GB |
| PLaMo 3 Translate 2B | Q4_K_M | 1.81 GB |

- 로컬 GGUF 실행 엔진을 llama.cpp 1.0.0의 Windows Vulkan 빌드 **b12359**로 갱신했습니다. 첫 실행 시 새 엔진을 내려받습니다. [llama.cpp 릴리즈](https://github.com/ggml-org/llama.cpp/releases/tag/v1.0.0)
- 모델 화면에 저장공간, RAM·VRAM 참고치, 제작자와 라이선스, 대상 언어 설정 예시를 표시합니다.
- 한국어로 번역하려면 연결 앱의 시스템 프롬프트에 `[plamo-translate] target_lang=ko`를 넣으세요. 일본어로 번역할 때는 `ja`, 영어는 `en`을 지정합니다. 원문 언어는 자동 감지합니다. [PFN API 예제](https://huggingface.co/pfnet/plamo-3-translate-2b-GGUF#translating-with-the-api)

기존 Cat Loader를 트레이에서 완전히 종료하고 **CatLoader-0.1.1-win-x64.exe**를 실행하세요. Windows x64용 **.NET 10 Desktop Runtime**과 **ASP.NET Core Runtime 10**이 필요합니다. 기존 모델 파일과 설정은 그대로 사용합니다. [Microsoft 런타임 다운로드](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)

두 PLaMo 모델의 신규 다운로드와 파일 검증, 일본어↔한국어 API 응답을 확인했습니다. 기존 GGUF 모델 5개도 새 엔진에서 실행해 응답을 받았습니다. Windows UI와 17개 언어 검사를 통과했습니다.
