# Cat Loader 0.4.5

Gemma Model Launcher와 CatRoute의 핵심 기능을 하나의 Windows 앱으로 통합한 정식 릴리즈입니다.

- **로컬 모델:** 기본 모델 6개를 바로 고르고 필요한 파일을 다운로드해 시작합니다. Translate Gemma E2B/E4B, HY-MT2 1.8B/7B, Gemma 12B와 ANIS Trans(일본어 ↔ 한국어)를 제공합니다. 사용자 GGUF·공개 Hugging Face 모델도 연결할 수 있습니다.
- **ChatGPT 연결:** 계정 로그인·로그아웃과 API 서버 켜기·끄기를 구분했습니다. 로그인은 브라우저에서 진행하고, API 서버 실행은 별도로 선택합니다. 사용량 조회·연결 진단·키 복사를 제공하며 로컬 모델과 함께 실행할 수 있습니다.
- **남은 사용량:** 사용한 비율을 표시하지 않고 기간별 남은 비율만 보여줍니다. 사용 0%는 `남은 사용량: 100%`입니다. 정보가 없으면 0%로 추측하지 않습니다.
- **모델 리소스 안내:** 선택한 모델의 저장공간, 첫 설치 권장 여유공간과 기본 RAM·VRAM 추정치를 다운로드 전에 표시합니다. 추정치와 실행 중 실측값을 구분합니다.
- **화면과 복구:** 기본 글자 크기, 공통 내비게이션, 작은 창의 버튼 배치, 프롬프트 편집을 정리했습니다. 인증 오류·시간 초과·예기치 않은 엔진 종료에 복구 안내를 추가했습니다. 17개 언어를 지원합니다.

Windows x64용 단일 EXE입니다. **.NET 10 Desktop Runtime(x64)과 ASP.NET Core Runtime 10(x64)**이 필요합니다. .NET 10 SDK에는 둘 다 포함됩니다. 기존 런처와 CatRoute를 완전 종료한 뒤 실행하세요. 기존 모델·프리셋·계정·로컬 키 저장 위치를 유지합니다. ANIS는 공식 출처와 이용 조건을 안내하고 필요한 접근 승인·토큰을 받아 다운로드합니다.

Core·네이티브 UI 회귀와 번역·패키지 검사를 수행했습니다. 실제 개인 계정의 OAuth 완료·로그아웃/재로그인·upstream 추론과 ANIS 승인 가중치의 실제 번역은 이번 검증에 포함하지 않았습니다. 자세한 결과와 추정치의 한계는 저장소의 `docs/reviews/2026-11-11-cat-loader-0.4.5-release.md`, `docs/model-resource-estimates.md`에 기록합니다.
