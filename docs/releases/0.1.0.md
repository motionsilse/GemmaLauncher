# Cat Loader 0.1.0

Cat Loader의 정식 릴리즈 번호를 **0.1.0**부터 새로 시작합니다. 기존 Gemma Launcher와 Cat Loader 0.4.x 릴리즈를 대체합니다.

**2026-11-11 수정 재배포:** Hugging Face 로그인은 성공했는데 앱에서 실패로 표시하던 오류를 수정했습니다. 실제 OAuth 응답의 `.` 문자를 잘못 거부하던 인증·다운로드 검사를 고쳤습니다. 이전에 0.1.0을 받았다면 아래 EXE를 다시 받아 교체하세요. 버전 번호가 같아 앱의 새 버전 알림은 표시되지 않습니다.

## 달라진 점

- 로컬 모델 6개와 ChatGPT 연결을 한 앱에서 사용합니다. 로그인·로그아웃과 API 서버 켜기·끄기를 구분하고, 두 서버는 독립적으로 동작합니다.
- 모델 선택 시 저장공간과 RAM·VRAM 참고치를 표시하고, 실행 버튼 옆에 대상 모델명을 보여줍니다.
- 다운로드 상태를 현재 단계·진행률·받은 용량으로 표시합니다. 실행 중 다른 모델을 선택하면 기존 로컬 서버를 종료한 뒤 선택을 바꿉니다.
- ANIS Trans는 일본어 ↔ 한국어 방향을 자동으로 고릅니다. 접근 권한이 필요한 경우 공식 Hugging Face 로그인 후 앱으로 돌아와 다운로드를 진행하며, 재시도 시 인증을 재사용합니다. 파일 검증과 Windows 서버 시작 오류를 수정했습니다.
- 공통 API 연결 정보를 모델 설명 아래로 옮기고, 제작자 표기를 우측 하단에 배치했습니다.
- 새 정식 버전이 있으면 앱에 다운로드 알림이 나타납니다. 누르면 공식 릴리즈 페이지로 이동합니다.
- 설정 파일을 저장할 수 없는 경우 오류를 표시하고 화면 이동·언어 변경이 중단되지 않도록 수정했습니다.

## 설치와 기존 버전에서 전환

1. 기존 Cat Loader를 트레이에서 **완전 종료**합니다.
2. 아래 첨부 파일 **CatLoader-0.1.0-win-x64.exe**를 받아 실행합니다.
3. Windows x64용 **.NET 10 Desktop Runtime**과 **ASP.NET Core Runtime 10**이 필요합니다. [Microsoft 다운로드](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)

기존 모델·설정·계정 데이터는 그대로 사용합니다. **0.4.x에서 이번 0.1.0으로 넘어갈 때는 EXE를 직접 받아야 합니다.** 이후 새 버전은 앱의 업데이트 알림으로 안내합니다. 첨부된 `.sha256` 파일로 다운로드 무결성을 확인할 수 있습니다.

초기 배포의 Release 빌드·네이티브 UI·17개 언어 검사에 더해, 수정본에서 Core 전체 검사와 실계정 ANIS 통합 테스트를 통과했습니다. 기존 브라우저 로그인 세션으로 실제 OAuth 코드 교환 → 네 모델 파일 300.9 MB 신규 다운로드·해시 검증 → 전용 실행환경 신규 설치 → 모델 로드 → 일본어/한국어 각 5문장 번역 → 종료·재로드를 확인했습니다. 컴퓨터 유즈 없이 앱과 동일한 인증·다운로드·공용 API 중계 코드를 실행했습니다. [실계정 검증 및 수정 리뷰](https://github.com/motionsilse/GemmaLauncher/blob/v0.1.0/docs/reviews/2026-11-11-anis-live-e2e.md)
