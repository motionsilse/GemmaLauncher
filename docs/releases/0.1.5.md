# Cat Loader 0.1.5

로컬 모델 목록에서 **Translate Gemma 4 Sub** 바로 아래에 **Unsloth Gemma 4 QAT E2B**와 **E4B**를 추가했습니다. 기본 모델은 총 10개입니다.

- Unsloth의 `UD-Q4_K_XL` GGUF와 각 모델에 맞는 MTP 가속 파일을 사용합니다.
- 네 Gemma 소형 모델의 설명에서 번역 튜닝과 4비트 최적화의 차이를 확인할 수 있습니다. 좁은 창에도 `Sub`와 `Unsloth QAT`가 표시됩니다.
- RTX 5080의 기본 실행 설정에서 확인한 RAM·VRAM 참고값을 새 모델에 표시합니다. [측정 조건과 참고값](https://github.com/motionsilse/GemmaLauncher/blob/v0.1.5/docs/model-resource-estimates.md)

두 모델의 파일 무결성, 서버 시작, 한영·영한 OpenAI 호환 API 응답을 확인했습니다. Windows UI 회귀 테스트와 17개 언어 검증을 통과했습니다.

기존 Cat Loader를 트레이에서 종료하고 `CatLoader-0.1.5-win-x64.exe`를 실행하세요. Windows x64용 **.NET 10 Desktop Runtime**과 **ASP.NET Core Runtime 10**이 필요합니다. [Microsoft 런타임 다운로드](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
