## 이전 초안에서 다시 정한 점

1. 전체 모델을 노출하는 것만으로 부족하다. 모델 정체성·실행·연결 정보의 위치와 위계를 고정한다.
2. 세부 설정과 출처를 긴 기본 버튼 목록으로 표시하지 않는다. 한 화면의 주 동작은 하나다.
3. 프롬프트 편집은 넓은 지시문/용어집 영역을 쓰고, 초안을 명시적으로 저장·버린다.
4. ANIS 수동 폴더 연결만을 기본 흐름으로 강제하지 않는다. 공식 접근 권한 연결 후 자동 준비를 제안하며, 이미 받은 폴더는 대체 경로로 제공한다.
5. 초기 모델 선택·순서·시각 토큰 등 설계자가 제안한 부분을 사용자 확정 요구와 구분한다.

## 구현 시 순서

1. 설계 시안의 사용자 피드백을 반영해 구조와 문구를 확정한다.
2. 현재 WinForms 초안의 모델 카탈로그 직접 노출·선택 롤백 등 유효한 부분을 재사용한다. 새 화면과 맞지 않는 UI 배치만 교체한다.
3. 프롬프트 저장 초안/적용 상태와 공유 설정 참조 처리를 먼저 테스트한다. 기존 암묵적 저장에 대한 기대를 갱신한다.
4. ANIS 엔진·기능 정보를 명시하고 권한 있는 공식 다운로드, 파일 검증, 전용 런타임 준비, 기존 포트의 API 제공을 구현한다.
5. 실제 WinForms 화면에서 크기·DPI·키보드·17개 언어·작업 취소와 프로세스 정리를 확인한다.
6. 정당하게 접근 가능한 ANIS 가중치로 실제 일본어↔한국어 요청을 검증하고, 구현/테스트 결과와 제한을 기록한다.

## 계획 작성 당시 확인한 상태

- 중단 전 로컬 초안은 Release 빌드가 성공했다.
- 중단 전에 시작한 `artifacts/ux-tests.log`는 WinForms controller and native-control tests passed로 끝난다. 이것은 **이전 초안**의 테스트이며 새 설계의 구현 검증은 아니다.
- ANIS 카탈로그·런타임·실제 번역은 아직 구현되지 않았다.
- 현재 세션의 브라우저 도구는 `Local browser use is disabled in Work settings`를 반환했다. 해당 제한을 다른 브라우저 도구로 우회하지 않는다. 대화용 시안은 정적 구조·스크립트를 확인하고, 실제 브라우저 렌더링 검증 여부를 분리해 보고한다.
- 시안의 JavaScript 문법, 중복 ID, label 대상, 여섯 기본 모델 정의, 외부 API 요청 없음, 파일 크기 제한을 확인했다. 브라우저에서의 배치·상호작용 테스트를 통과했다는 의미는 아니다. 검토용 로컬 서버는 종료했다.
- 사용자 진행 지시 후 1차 리뷰 R1–R5를 설계·시안에 반영했다. 독립적인 초안 수명, 공유 설정 영향과 복제, 대상별 삭제, 모든 작업 화면의 중지 제어, 원인별 실패 복구를 포함한다. 시안의 DOM 이벤트·상태 회귀 테스트 22개가 통과했다. 실제 Windows UI 적용은 이후 단계다.
