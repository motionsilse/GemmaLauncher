# PLaMo 요청 호환성 수정

CatBridge가 전달한 언어 정보와 원문 구분자를 PLaMo가 번역문에 포함하면서 응답 검사를 통과하지 못했다. Cat Loader의 PLaMo 모델 경로에 요청 변환을 추가했다.

원문·대상 언어가 명시된 원문 블록을 읽어 언어를 PLaMo 템플릿 옵션으로 옮기고, 원문만 번역 대상으로 전달한다. 부가 문맥은 별도 system 메시지로 보존한다. 명시적인 PLaMo 옵션은 우선하며, 알 수 없거나 중복된 언어 정보는 400 응답으로 처리한다. 원문 내부의 링크 토큰과 배치 마커는 유지한다.

0.8B와 2B의 설명과 제목을 17개 언어에서 구분했다. 0.8B는 응답 속도와 메모리 부담, 2B는 번역 품질을 우선하는 선택으로 설명한다.

## 검증

- 기존 코드에서 원문 구분자가 그대로 전달되는 실패를 재현한 뒤 회귀 검사를 추가했다.
- CatBridge의 실제 번역 엔진 코드를 로컬 진단에서 호출했다. 0.8B와 2B 각각 영어→한국어, 일본어→한국어, 한국어→일본어에서 변환 전 오류를 재현하고, 변환 후 6개 요청이 번역 결과와 기존 응답 검사를 통과했다.
- 실제 PLaMo 모델 2개의 다운로드·해시 검사와 기존 PLaMo 요청 및 원문 블록 요청을 확인했다. 기존 GGUF 모델 5개도 로드·응답·종료를 통과했다.
- Core 전체 검사, Windows 네이티브 UI 검사, 17개 언어 및 카탈로그 검사를 통과했다.

재리뷰에서 원문 블록 앞의 참고 문맥이 손실되는 문제를 보완하고 다시 실검증했다. 변환 범위는 언어 라벨과 원문 블록을 사용하는 Chat Completions 요청이다. 임의의 자연어 지시문을 분석해 번역 대상을 추측하는 기능은 포함하지 않는다.
