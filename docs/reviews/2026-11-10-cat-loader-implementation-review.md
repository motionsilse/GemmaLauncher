# Cat Loader 구현 최종 리뷰

> 2026-11-11 후속 판단: 아래 기능·안전성 검사 결과는 ChatGPT 화면의 UX 통과를 뜻하지 않는다. 사용자가 로그아웃 접근성, 설명, 버튼과 레이아웃을 문제로 지적했고 기존 UX 승인은 철회했다. [재설계 검토 기록](../design/2026-11-11-chatgpt-redesign/review.md)에서 시안 검사와 실제 앱에 남은 검증을 분리해 관리한다.

AGENTS.md에 따라 본 에이전트가 순차 검토했다. 독립 리뷰 에이전트는 실행하지 않았다. 제품 변경 범위는 `f4763d9`부터 최종 통합 커밋까지다.

- **정확성·계약:** 두 API 주소와 모델 식별자를 보존했다. 엔진 생존과 준비 상태가 다르며 사용량 조회는 추론이 아니다. 콜백 state/중복·응답 크기·모델 ID 중복 제거·한도 누락을 검사했다.
- **저장·보안:** 실제 사용자 폴더 대신 임시 폴더에서 키 보존·손상 키 덮어쓰기 거부·독점 잠금·codex만 삭제를 검사했다. 소유권은 서비스가 유지하며 host가 별도 잠금을 획득하지 않는다. 관리 키와 외부 앱 키를 분리하고 localhost·리다이렉트/프록시 금지·출력 폐기를 원본에서 유지했다.
- **수명:** 두 기능의 실제 VM과 가짜 호스트로 시작/중지 독립성, 조회 취소, 오류/무응답 정리, 종료 중 버튼 비활성 상태를 검사했다. 로그인 중 카테고리 이동은 연결을 중단하지 않는다. 정리 실패는 성공으로 표시하지 않는다.
- **UI:** 공통 배경 작업 패널의 미생성 VM 참조 오류와 두 기능 동작 시 로컬 주 버튼이 화면 밖으로 밀리는 오류를 발견해 수정했다. 마지막으로 배경 중지 버튼의 활성 상태도 회귀 검사 후 맞췄다. 키는 기본 마스킹하며 새 연결/숨김/기능 전환 시 다시 가린다.
- **범위·배포:** 연구·payload 프로젝트·CatBridge 바이너리 의존성이 없다. 기존 .NET shared frameworks를 사용하고 고정 엔진은 별도 다운로드한다. 최종 EXE는 1.28MiB이며 utility 검증이 통과했다. 이전 배포물과 원본 저장소는 보존했다.

필수 로컬 빌드·Core·UI·locale·catalog·script 검사와 공식 엔진 첫 사용 smoke가 통과했다. 상세 수치·산출물·실계정 미검증 범위는 [작업 기록](../work/2026-11-10-cat-loader-integration.md)에 기록했다. 이 리뷰는 실제 OAuth/추론 종단 성공을 대신하지 않는다.
