- 전체 Core 콘솔 테스트: 통과.

- 수정 회귀 검사: 통과 (`review-fixes-red.log`, `review-fixes-green.log`).
- 지역화: 17개 언어, 3개 도메인, 언어당 451개 키와 placeholder 일치.

- 실제 HWND 렌더링: 사용량 화면 17개 언어, 설정, 최소 창의 세 가지 오류 화면 캡처 (`artifacts/cat-loader/review-screens/`). 한국어 설정·오류·사용량과 독일어·러시아어 사용량 화면을 직접 확인했다.

## 재리뷰

수정한 코드, 테스트, 17개 언어의 키·인자, 공통 설정 대화상자와 기존 로그아웃 확인창의 차이를 재검토했다. 사용자 취소와 내부 deadline, 정리 중 명령 허용 여부, 조회 실패 후 연결 유지, 설정의 자동 저장/닫기, 기간 누락을 다뤘다. 이 수정 범위에서 추가로 남은 P0–P3 문제를 발견하지 못했다. 테스트는 사용자 계정 대신 가짜 연결과 임시 상태를 사용했다. 실제 계정 OAuth와 ChatGPT upstream 응답은 이번 검사에 포함하지 않는다.
