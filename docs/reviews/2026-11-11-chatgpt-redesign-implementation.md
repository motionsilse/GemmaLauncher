# ChatGPT 연결·공통 내비게이션 적용과 검증

2026-11-11 · Cat Loader 0.4.3 · 작업 브랜치 `codex/anis-trans`

> 후속 재리뷰에서 발견한 4개 UX/UI 문제는 0.4.4에서 수정했다. 현재 수정 내용과 검증 한계는 [수정·재리뷰 기록](2026-11-11-chatgpt-four-fixes.md)을 따른다. 아래는 0.4.3의 적용 이력이다.

## 적용 결과

[재설계](../design/2026-11-11-chatgpt-redesign/design.md)를 네이티브 WinForms 앱에 적용했다. 계정과 API 서버를 나란히 배치하고, 좁은 창에서는 계정 요약 다음에 서버를 배치한다. 로그아웃을 계정 옆에 노출하고 사용량·사용 방법·진단은 목적에 맞게 별도 보기로 제공한다. 상단 탐색은 텍스트와 밑줄로 표시하며 하단에는 두 기능의 상태와 중지·취소를 유지한다.

로그인은 계정 저장만 담당한다. 인증에 필요한 보조 프로세스는 별도 임시 loopback 포트를 사용하고 완료·취소·실패 뒤 종료한다. 사용자 API 포트는 별도의 서버 켜기로 연다. 서버 끄기는 로그인을 보존하고, 확인 후 로그아웃은 이 PC의 로그인만 제거한다. 기존 계정 폴더·키·모델 6개·두 API 주소를 보존했다. 웹 런타임이나 패키지 의존성은 추가하지 않았다.

본문은 ChatGPT 화면에서 12pt, 보조 문구는 10.5pt를 사용한다. 작은 창에서 로고 제목을 생략하고 긴 탐색 이름의 줄바꿈을 처리한다. 계정과 서버의 중요 동작을 찾기 위해 접힌 영역을 열 필요가 없다. API 값은 준비 완료 시에만 표시하며, 키 표시 후 화면 이동 시 다시 마스킹한다. 서버 실행 중에도 인터넷과 ChatGPT 계정 한도 안내를 유지한다.

## 재현·수정한 문제

- 구현 전 네이티브 회귀 테스트가 로그인 전 연결값 노출과 접힌 로그아웃 때문에 실패함을 확인했다.
- 초기 적용의 상단 FlowLayout 선호 크기 계산이 헤더를 187px로 늘렸다. 실제 가용 너비로 높이를 계산해 기본 창에서 79px로 줄였다.
- 긴 번역에서 작은 창의 탐색이 줄바꿈되며 주요 동작을 밀어냈다. 좁은 창의 로고를 줄이고 계정 영역 높이를 보이는 내용에 맞춰 계산했다.
- 계정 영역의 숨긴 사용량 행이 여백을 남기는 문제를 수정했다.
- 정리 실패 후 중지 재시도를 막지 않도록 고쳤다. 오류를 완료로 표시하지 않으며 로그아웃 전 정리를 다시 시도할 수 있다.
- 최초 다운로드 테스트에서 브라우저 콜백 내부의 검증 예외가 앱의 오류 처리에 흡수될 수 있어, 관찰 결과를 콜백 밖에서 검증하도록 했다.

## 산출물과 남은 확인

- `dist/CatLoader-0.4.3-win-x64.exe`: **1,415,793 bytes**
- SHA-256: `fb307e93811d61344406b03ff9793b2d11490c64f55337dbcce43c6c1811d523`
- 패키지 검사 보고서를 작업 증거로 보존하고 이번 빌드의 임시 publish 디렉터리는 정상 삭제했다. 기존 배포물은 보존했다.
- 커밋·푸시·공개 릴리즈는 수행하지 않았다.

실제 사용자 계정의 OAuth 완료·로그아웃 후 재로그인·외부 앱의 실제 추론 요청은 수행하지 않았다. 물리 모니터의 150%·200% DPI 전환과 사용자 본인의 사용성 판단도 남아 있다. 자동 검사 통과가 이 검증이나 UX 승인을 대신하지 않는다. 이 검토는 본 에이전트의 순차 자체 검토이며 독립 리뷰어의 승인으로 표현하지 않는다.
