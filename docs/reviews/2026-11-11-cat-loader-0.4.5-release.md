# Cat Loader 0.4.5 릴리즈 전 최종 검토

2026-11-11 · 순차 자체 리뷰. 독립 리뷰어의 승인이나 실제 계정 검증을 뜻하지 않는다.

## 반영한 요청

- 계정 한도는 `남은 사용량`만 표시한다. 사용 비율은 표시하지 않는다. 0% 사용 → 100% 남음, 20% 사용 → 80% 남음, 100% 사용 → 0% 남음이다. 없는 값·잘못된 값은 정보 없음이다. 기간·초기화 시각·조회 시각은 유지한다.
- 기본 모델 6개를 선택하면 모델 저장공간, 첫 설치 권장 여유공간과 RAM·VRAM 참고치를 표시한다. 기본 대화 길이와 CPU/GPU 조건을 함께 안내하고 실행 중 실측값은 별도로 유지한다. [추정 근거와 한계](../model-resource-estimates.md)를 기록했다.
- 이전 미배포 작업인 공통 내비게이션, ChatGPT 로그인과 서버 실행 분리, 로그아웃, 가독성, 인증 복구·진단·엔진 종료·접근성 수정도 포함한다. 상세 이력은 [4개 수정 재검토](2026-11-11-chatgpt-four-fixes.md)를 참고한다.

## 검토 중 정리한 항목

1. 크기를 모르는 사용자 모델에 실행환경 여유 2 GB만 표시하면 전체 설치 예산처럼 보인다. 파일 크기가 모두 알려진 경우에만 설치 여유공간을 계산하도록 수정했다.
2. 사용자 모델에 메모리 정보가 없거나 NaN 등 잘못된 정보가 있으면 기본 모델의 값을 추측하지 않는다. 기존 로컬 파일은 재다운로드·복사 예산에서 제외한다.
3. README의 예전 `Start connection` 안내를 로그인 후 서버 켜기로 수정하고 한국어 계정 흐름도 추가했다. 업데이트 안내의 오래된 EXE 파일명도 최신 정식 릴리즈 안내로 바꿨다.
4. UI 테스트의 모델 선택 직후 비교가 비동기 바인딩 갱신보다 먼저 실행됐다. 실제 선택 안내가 반영된 뒤 실행 전후를 비교하도록 테스트를 수정했다. 제품 코드의 추정치를 실측값으로 덮어쓰는 문제는 재현되지 않았다.

## 결론과 검증 범위

한도 방향, 미지 값, 저장공간 중복 계산, 메타데이터 호환성, 기본 설정과 실측 구분, locale 갱신, 계정 상태·복구, 키보드·접근성 이름, 작은 창과 패키지 포함 여부를 검토했다. 위 수정 후 이 범위에서 추가 P1/P2 문제를 발견하지 못했다. 이전 공개 v0.2.0 이후의 통합 변경을 v0.4.5 정식 릴리즈로 배포한다. 최종 EXE의 해시는 릴리즈에 첨부한 SHA-256 파일로 제공한다.

실제 사용자 계정의 OAuth 완료·실계정 로그아웃/재로그인·upstream 추론, ANIS 승인 가중치의 번역, 모든 GPU에서의 메모리 측정, 물리 모니터 DPI 전환은 수행하지 않았다. 한도·로그아웃 흐름 검사는 테스트 서비스를 사용했다. RAM·VRAM 안내는 구매나 실행 가능성을 보장하는 최소 사양이 아니다.
