# Cat Loader 0.1.0 릴리즈 전 최종 검토

2026-11-11 · 순차 자체 리뷰. 독립 리뷰어의 승인이나 실계정 인증 완료를 뜻하지 않는다.

## 검토 범위와 수정

- 공개 0.4.6 이후 작업본 0.4.9까지의 다운로드·인증·모델 전환·공통 연결 영역·업데이트 알림 변경을 검토했다. 앱 버전과 배포 스크립트 기본값을 0.1.0으로 변경했다.
- ANIS는 익명 다운로드를 먼저 시도한다. 접근 권한이 필요하면 공식 OAuth와 PKCE로 인증하며, 다운로드 재시도 때 메모리에 남은 인증을 재사용한다. 개별 JSON 파일을 브라우저로 열거나 토큰을 붙여 넣게 하지 않는다. 네 파일의 크기와 고정 해시를 검사한 뒤 설치 완료로 인정한다.
- 인증 대기 중에는 다운로드 진행률을 표시하지 않는다. 실제 전송 때만 백분율·받은 용량을 표시한다. 전송 정체에는 제한 시간이 있으며 취소 시 임시 파일을 정리한다. 인증 헤더는 Hugging Face 원본에만 전달한다.
- ANIS의 Windows Python 자식 프로세스가 같은 작업 객체에 속하는지 확인하고, 공식 API가 처리하는 모델 경로를 사용하도록 한 시작 오류 수정도 검토했다.
- 실행 중 다른 로컬 모델을 고르면 기존 서버를 끈 뒤 선택을 바꾼다. 종료 실패·취소 시 이전 선택을 유지하고 새 모델은 사용자가 실행한다. ChatGPT 연결과 로컬 서버의 수명은 독립적이다.
- **최종 테스트에서 추가 발견한 결함:** 공통 설정 저장의 파일 교체 오류가 언어 변경·트레이 설정·화면 이동까지 전파됐다. 읽기 전용 설정 파일로 동일한 `UnauthorizedAccessException`을 재현했다. 저장 실패를 공통 화면과 설정창에 표시하고, 메모리의 선택과 화면 이동은 유지하도록 수정했다. 기존 저장 파일을 보존하며 다음 저장 성공 시 오류 안내를 해제한다. 처음 관측된 일시적인 OS 접근 거부의 원인 프로세스는 특정하지 않았다.
- README의 수동 서버 종료 안내를 실제 모델 전환 동작과 맞췄다. 0.4.x → 0.1.0은 번호가 낮아지는 변경이므로 이번 전환은 EXE를 직접 받아야 함을 명시했다.
- 배포 스크립트가 파일명뿐 아니라 EXE 내부 버전도 요청한 릴리즈 버전과 일치하는지 확인하도록 보강했다.

## 검증의 한계와 배포 절차

실제 Hugging Face 계정의 승인부터 인증된 원격 다운로드까지의 전 구간은 이번 검토에서 실행하지 않았다. OAuth 코드 교환·PKCE·잘못된 state 거부·인증 재사용·리디렉션 헤더 경계는 모의 HTTP와 실제 로컬 콜백으로 검사했다. 실제 ANIS 서버 시작과 번역에는 이미 해시 검증을 마친 모델을 사용했다. ChatGPT 로그인/로그아웃도 네이티브 화면에서 모의 계정 서비스를 사용한 검사이며 개인 계정의 실인증 검증은 아니다.

소스 커밋을 확정한 뒤 해당 커밋에서 최종 EXE를 다시 빌드한다. 새 정식 릴리즈와 다운로드한 파일의 SHA-256을 확인하고, 사용자가 명시한 이전 릴리즈 7개를 삭제한다. 기존 Git 태그·소스 이력·사용자의 모델과 설정은 삭제 대상이 아니다.
