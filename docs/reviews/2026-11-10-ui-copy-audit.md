# 버튼·문구 동작 대조 점검

2026-11-10 · 실제 WinForms UI 및 명령 처리 코드를 순서대로 검토했다. 기존 화면 디자인과 모델 동작은 유지하면서, 사용자가 문구만 보고 다음 결과를 예측할 수 있는지 확인했다.

## 점검 범위

- 메인: 모델 선택, 파일 상태, 준비·시작·중지·취소, 프리셋 선택, API 연결·복사, 출처 링크.
- 모델 추가: 로컬 GGUF 연결, Hugging Face 조회·추가, 사용자 모델 선택·제거, 기존 폴더·카탈로그 연결, 빈 목록·실패 상태.
- 프리셋: 새 초안·복사·공유, 저장과 적용, 미적용·미저장 상태, 이동 확인, 삭제, 생성 옵션.
- 설정: 표시 언어, 창 닫기 동작, 자동 저장, 고급 실행 옵션·초기화·재시작.
- ANIS: 최초 권한 입력, 다운로드·실행, 번역 방향, 실행 장치.
- 공통: 오류 복구 버튼, 필수 구성요소 안내, 로그·폴더 열기, 트레이 복원·서버 제어·완전 종료.

## 발견과 조치

| 영역 | 혼동되는 표현·상태 | 확인한 동작과 반영 |
|---|---|---|
| 복귀 | 좌상단 ‘실행’ | 앞선 수정인 ‘← 모델 선택으로’를 모든 보조 화면에서 재확인. 편집 하단 복귀 버튼도 같은 문구 사용. |
| 고급 설정 | ‘취소’를 누르면 값을 되돌릴 것처럼 보임 | 이미 자동 저장하므로 ‘닫기’로 변경. 자동 저장과 다음 서버 시작·재시작 때 적용함을 안내. |
| 일반 설정 | 트레이 옵션을 꺼도 트레이에서 종료하라고 안내 | 현재 체크 상태에 따라 창 닫기 시 서버·런처 종료 또는 트레이 안내를 표시. 자동 저장·닫기 문구 명시. |
| 로그 | ‘오류 세부 정보’, ‘실행 로그’가 문서나 상세 창처럼 보임 | 실제로 폴더를 열므로 ‘로그 폴더 열기’로 통일. |
| 필수 구성요소 | ‘Windows 실행 구성요소 설치’ | 버튼은 Visual C++ 설치 파일의 다운로드를 여므로 ‘Visual C++ 설치 파일 받기’로 변경. |
| Hugging Face | ‘파일 찾기’가 PC에서 찾는 동작처럼 보임 | ‘저장소 파일 조회’와 ‘추가할 GGUF 파일’로 대상을 명확히 함. ‘추가하고 선택’은 실제 다운로드·실행과 구분해 유지. |
| 사용자 모델 | ‘내 모델’ 안내가 기본 모델까지 포함한다고 설명 | 실제 목록 범위에 맞춰 ‘추가한 모델’과 원본 파일 보존 안내로 변경. |
| 빈 모델 목록 | 대상이 없는데 ‘이 모델 선택’이 활성화됨 | 유효한 모델 대상이 있을 때만 선택 명령을 활성화. |
| 저장과 적용 | 다른 프리셋을 저장만 해도 다음 요청에 사용된다고 안내 | 저장만 한 경우 ‘설정을 저장했습니다’, 저장·적용한 경우 현재 모델 적용 안내로 구분. |
| 미적용 프리셋 | 현재 모델이 쓰지 않는 설정에도 적용 중처럼 안내 | 미적용 상태와 ‘저장하고 적용’ 필요 여부를 표시. 설정이 없는 경우 일반 생성 안내 사용. |
| 복제 | ‘현재 모델용으로 복제’가 즉시 적용처럼 보임 | 실제로 독립적인 미저장 초안을 만드므로 ‘복사본 만들기’로 변경. |
| 편집 이동 | 편집 화면의 ‘취소’와 확인 창의 ‘취소’가 모두 같은 의미처럼 보임 | 화면 이동은 ‘← 모델 선택으로’, 확인 창에서 이동을 중단하는 선택은 ‘계속 편집’, 폐기는 ‘변경 버리기’로 구분. |
| 복구 | ‘포트 다시 확인’, ‘다시 다운로드’가 진단·다운로드만 할 것처럼 보임 | 실제 서버 시작까지 포함하므로 ‘포트 확인 후 서버 시작’, ‘다시 다운로드하고 시작’, ‘서버 시작 다시 시도’로 명시. |
| 추가 실패 | 추가 작업 실패가 서버 시작 실패로 표시되고 실행 버튼이 다른 작업의 재시도처럼 바뀜 | 서버 오류와 일반 작업 오류를 구분. 추가 실패가 기존 모델의 시작 버튼·서버 복구 경로를 바꾸지 않도록 수정. |
| 적용 대기 | GPU 등 실행 옵션을 바꿔도 글 길이만 재시작한다고 안내 | ‘변경한 실행 설정’ 전체로 안내 범위 수정. 이전 실패의 복구 종류도 새 작업 시작 때 초기화. |
| 고급 선택·범위 | auto/on/off 등 내부 값과 영어 고정 숫자 제목 | 자동·켜기·끄기·전체와 장치 표시로 정리. GPU 값 안내를 표시하고, Temperature와 Top P 범위 및 생성 옵션 제목의 언어 변경을 반영. 저장되는 실제 옵션 값은 유지. |
| 초기화 | 직접 연결한 MTP 해제까지 포함하는지 불분명 | 버튼 앞에서 권장값 복원·MTP 연결 해제·원본 보존을 안내. |
| 준비·연결 | 파일 준비가 서버 실행·API 연결 가능처럼 보일 수 있음 | ‘모델 파일 필요/준비 완료’와 API의 서버 시작 전 대기 상태를 분리. 모델 식별값은 ‘API 모델 이름’으로 표시. |
| 확인·삭제 | 긴 안내가 잘리고 삭제 영향이 불분명 | 대화상자 메시지 줄바꿈을 수정하고, 삭제 후 해당 모델들이 기본 설정으로 돌아감을 안내. 새 초안을 편집하거나 설정을 삭제하면 과거 저장 알림이 남지 않게 정리. |
| 비활성 표시 | 누를 수 없는 추가 버튼도 초록색 주 버튼으로 보임 | 비활성 주 버튼은 회색 배경과 기본 커서로 구분. |
| 옵션 검증 | 호환되지 않는 옵션을 고르면 값만 돌아가고 설명은 대화상자 뒤 메인 화면에 표시 | 설정 창 안에 검증 이유를 표시하고, 유효한 변경으로 해결하면 안내를 지움. |

## 검증

- 수정 전 모델 추가 실패 회귀 테스트가 실패함을 재현한 뒤 수정했다.
- 전체 네이티브 컨트롤·상태 테스트가 통과했다. 추가 실패, 빈 선택 대상, 초안 저장, 공유·복사·삭제, 취소·중지·재시작, 옵션 오류와 언어 전환을 확인했다.
- 변경 문구는 17개 언어에 반영했으며, 키·서식 검사 기준은 언어당 380개다.
- 실제 네이티브 캡처: `artifacts/ux-redesign/{main,page-1,preset-inactive,preset-shared,preset-shared-compact,settings,settings-exit,load-options,unsaved-dialog,delete-dialog,import-error}.png`.
- 렌더링 과정에서 실제 저장 확인 대화상자를 열고 ‘계속 편집’ 결과가 화면과 초안을 유지하는지 확인했다. 삭제 확인은 취소해 원본 설정을 보존했다. 작은 창의 공유 프리셋 버튼과 두 가지 창 닫기 설정도 확인했다.
- 브라우저·외부 설치 파일·Explorer는 실제 실행하지 않고 연결된 명령의 목적지를 검토했다. 모델 다운로드·추론을 새로 수행한 점검은 아니며, 이전 첫 다운로드 검증과 구분한다. 수동 레이아웃 확대는 물리 모니터 DPI 검증이 아니다.
