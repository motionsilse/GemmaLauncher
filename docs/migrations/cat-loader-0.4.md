# Cat Loader 0.4 업데이트

기존 런처가 켜져 있다면 완전 종료한 뒤 최신 정식 Cat Loader Windows x64 EXE를 실행한다. 시스템 .NET 10 Desktop·ASP.NET Core 런타임이 필요하다.

- 로컬 모델·캐시·프리셋·추가 GGUF와 언어 설정은 기존 `%LOCALAPPDATA%\GemmaLauncher`를 사용한다. 모델을 다시 받을 필요가 없다.
- ChatGPT 계정·로컬 API 키는 기존 `%LOCALAPPDATA%\CatRouteCodexProxy`를 사용한다. DPAPI 범위·entropy와 키 형식을 바꾸지 않는다. 토큰을 별도 폴더로 복사하지 않는다.
- 기존 CatRoute가 실행 중이면 완전 종료한 뒤 연결한다. 파일 잠금 또는 포트가 충돌해도 다른 앱을 강제로 종료하지 않는다.
- 기존 런처 설정이 없을 때만 CatRoute의 표시 언어(auto/ko/en)를 가져온다.
- 기본 주소는 로컬 모델 `http://127.0.0.1:8080/v1`, ChatGPT `http://127.0.0.1:8319/v1`다. 두 기능의 서버와 키를 구분해 입력한다.
- 앱 시작과 최근 카테고리 복원은 자동 연결이 아니다. 로컬 모델은 서버 켜기를 누른다. ChatGPT는 로그인 후 서버 켜기를 별도로 누른다. 서버를 꺼도 로그인은 유지되며, 계정 영역의 로그아웃은 확인 후 저장 로그인을 삭제한다.
- 창 닫기의 트레이 설정은 두 기능에 공통 적용된다. 완전 종료는 두 기능을 정리한다.

CatRoute 저장소나 기존 릴리즈는 이 로컬 통합 작업에서 삭제·보관 처리하지 않았다. 실제 계정 로그인과 upstream 응답은 사용자의 브라우저 인증 이후 확인할 수 있다.
